# Trilha de Lógica de Programação

Repositório com os exercícios e projetos desenvolvidos durante meus estudos de **HTML, CSS, JavaScript e PHP**.

## 📋 Sobre

Este repositório reúne a trilha de aprendizado que segui nas aulas, organizando os conteúdos por módulos.  
Foi criado para registrar a evolução prática nos fundamentos do desenvolvimento web.

## 🗂️ Estrutura do Repositório

- **Modulo01 - HTML e CSS** → Estrutura de páginas e estilização
- **Modulo02 - JavaScript** → Lógica de programação e interatividade
- **Modulo03 - PHP** → Introdução ao back-end

## 🛠️ Tecnologias Estudadas

- HTML5
- CSS3
- JavaScript
- PHP

## 🎯 Objetivo

Registrar o progresso dos estudos e praticar os conceitos aprendidos em sala de aula, servindo como base para projetos futuros.
